# Provenance

- **Authorship.** Written for Adaptive Machine Patterns Ltd by Andy Whyte,
  with AI coding assistants (mostly Anthropic Claude). The output of these
  assistants belongs to the user under their providers' terms. All of it was
  reviewed and is published under Apache-2.0 by the copyright holder.
- **No third-party source code.** The package uses LeRobot's public plugin
  interface (`PreTrainedConfig`, `PreTrainedPolicy`, its processor steps) and
  PyTorch; it copies no code from either.
- **Origin.** The network is the same as AMP Tadpole's model package
  (huggingface.co/Adaptive-Machine-Patterns/amp-tadpole), with the same
  parameter names, written first in AMP's own research project.
